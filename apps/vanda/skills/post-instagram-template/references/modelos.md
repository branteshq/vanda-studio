# Modelos de layout: fichas completas

Transcrição de todos os slides do canvas "Templates de post Instagram". Formato 4:5, 1080×1350 px.
Cada ficha lista os elementos de cima para baixo, com tamanho em px, peso, família (serifa para títulos, sans para o resto) e o PAPEL da cor (não a cor final).
Script de cada slide: `/skills/post-instagram-template/assets/py/<ID>.py`. PNG e HTML não fazem parte desta skill.

Papéis de cor: escuro principal, fundo claro, DESTAQUE, branco (cartão), neutros. Troque cada papel pela cor da marca (ver diretrizes.md).

Todos os slides trazem no rodapé o selo "Modelo de layout · cores e fontes a definir pela marca". Ele NÃO entra na arte final e foi omitido das fichas.
