# Propósito: dados

- Objetivo: transformar dados em entendimento. Princípio: visualização de dados.
- Estrutura: o insight como título → gráfico → leitura do que o dado significa.
- Visual: um gráfico simples e correto por imagem ou slide (barras para comparar, linha para tendência), destaque na informação principal, fonte no rodapé.
- Texto e CTA: título com a conclusão, não o nome do gráfico ("Pedidos dobraram em agosto").
- Decisões de estilo: título é a conclusão; um gráfico simples por imagem ou slide; destaque só na série principal; fonte no rodapé.
- Evite: gráficos decorativos com proporções erradas, números sem fonte, excesso de séries.
- Fatos necessários: os números exatos e a fonte. Nunca invente ou arredonde sem avisar.
